2. **Archetype.** Numbered price-first list + combo cards.
3. **Navigation.** Numbered jump + a **sticky bottom action bar**.
4. **Card anatomy.** Big number tab (#12), **price-first** large, short name, combo badge, big
   targets (≥48px).
5. **Detail.** Inline expand + combo builder.
6. **Type.** Anton (heavy condensed) / **Cairo bold** (Arabic).

8. **Imagery.** Cutout product on a colour block; no-photo = big number + name block.
9. **Ornament.** Brutalist blocks, number tags, tape-strip accents.
10. **Motion + voice.** Snappy/instant (no slow fades); voice: punchy/street ("#12 · Chapati thon").

- **No-photo fallback:** number + name on colour block (the default look anyway).
