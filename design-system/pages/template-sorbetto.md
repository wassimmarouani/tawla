# Template — Glacier Sorbetto (artisanal ice cream)

Evolves `gelato`→ `templates/sorbetto/`. MATRIX row 10.

1. **Value proposition.** Playful choice for families: build your cup.
2. **Archetype.** Flavor **swatch grid**.
3. **Navigation.** Swatch grid → **scoop-builder** flow (pick 2/3 scoops).
4. **Card anatomy.** Colour chip + flavor name (never colour alone) + scoop-add button; price.
5. **Detail.** Bottom sheet scoop builder (choose scoops, cone/cup, toppings).
6. **Type.** Baloo 2 (rounded) / **Baloo Bhaijaan 2** (Arabic). Friendly.
7. **Palette.** Soft clay pastels; light.
8. **Imagery.** Illustrated colour swatches (no photos).
9. **Ornament.** Bouncy blobs, pastel confetti accents.
10. **Motion + voice.** Springy bounce, **reduced-motion safe** (spring → fade); voice: fun/family
    ("Compose ta coupe !").

- **Category header:** pastel pill label.
- **Empty/unavailable:** sold-out flavor = desaturated chip + "Épuisé"; empty = "Bientôt de retour".
- **Call/bill bar:** pastel bar, clay primary.
- **No-photo fallback:** the default — colour chip + name (always, no photos).
- **Data-deps:** **scoop builder** likely expressible with existing option groups (scoops/toppings
  as options) — confirm in engine work; otherwise optional fields, await approval.
