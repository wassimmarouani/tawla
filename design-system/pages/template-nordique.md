# Template — Pâtisserie Nordique (French fine pastry)

Evolves `atelier`→ `templates/nordique/`. MATRIX row 6. Opposite of La Rose.

1. **Value proposition.** Craft storytelling (composition, layers, allergens).
2. **Archetype.** Single-column lookbook, one large image per item.
3. **Navigation.** Vertical scroll + a minimal top index (category names, no tabs clutter).
4. **Card anatomy.** One large image; asymmetric caption (name + short line); allergen line.
5. **Detail.** Full detail page: composition, layer breakdown, allergens.
6. **Type.** Neue-grotesk thin (Latin) / **Alexandria** (Arabic). Editorial, airy.
7. **Palette.** Cool Nordic monochrome + one berry accent; light, maximal whitespace.
8. **Imagery.** One large editorial image per item; no-photo = full-width monochrome type card.
9. **Ornament.** None; a single thin rule, generous whitespace.
10. **Motion + voice.** Calm long fades; voice: craft/editorial ("Trois couches, une noisette").

- **Category header:** large thin label, lots of space above.
- **Empty/unavailable:** sold-out = desaturated image + quiet label; empty = minimal note.
- **Call/bill bar:** monochrome bar, berry accent on primary.
- **No-photo fallback:** monochrome type card (large name, berry rule).
- **Data-deps:** none (composition/layers go in description).
