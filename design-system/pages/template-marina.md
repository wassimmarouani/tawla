# Template — Café Marina (specialty coffee, smoothies, bowls)

Evolves `specialty` into `templates/marina/`. MATRIX row 2. Deliberate opposite of El Bahja.

1. **Value proposition.** Ingredient + dietary transparency.
2. **Archetype.** Bento grid, mixed card sizes (hero item spans 2×, others 1×).
3. **Navigation.** Sticky, prominent diet filters (veg/vegan/GF) + category tabs under them.
4. **Card anatomy.** Bento card: square photo top, name, diet icons row (icon+label, never colour
   alone), price bottom.
5. **Detail.** Bottom sheet with an ingredient/dietary breakdown list.
6. **Type.** Geist (geometric sans) + **IBM Plex Sans Arabic**. Crisp, neutral.
7. **Palette.** Sea-salt white, sage, sand, ink; light. Airy coastal minimalism.
8. **Imagery.** Framed square photos; no-photo = sage typographic tile.
9. **Ornament.** Fine hairline grid, a single coastal dot accent; lots of whitespace.
10. **Motion + voice.** Crisp, quick fades. Voice: clean/health-forward ("Frais, de saison").

- **Category header:** thin rule + label; filter state reflected.
- **Empty/unavailable:** sold-out dims card; filtered-empty = "Aucun plat ne correspond" + reset.
- **Call/bill bar:** minimal ink bar.
- **No-photo fallback:** sage monogram tile.
- **Data-deps:** none (diet flags already exist).
